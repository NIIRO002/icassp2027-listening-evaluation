# ICASSP 2027 GTSinger Listening Evaluation v2

Public listening evaluation for controllable singing voice conversion research.

## Open the evaluation

https://niiro002.github.io/icassp2027-listening-evaluation/

Each participant should receive one assignment slot from `01` to `24`. The evaluation contains 20 trials: 10 direction questions and 10 quality questions. It exports the completed anonymous response as a CSV file in the participant's browser. This static site does not automatically upload or store responses on a server.

Version 2 was rebuilt to reduce repeated excerpts. The candidate pool contains 36 excerpts across English, Korean, and Japanese sources, six source-to-reference transfer families, and 18 exact source-reference pairs. Twenty-four items are selected for the balanced assignment design. Every participant hears 20 different items, all six transfer families, at least 14 exact source-reference pairs, and at least 38 distinct audio files.

Responses from the previous 22-trial version must not be combined with this version. New response files identify the study as `icassp2027_gtsinger_diverse_human_evaluation_v2`.
